# 🐱 Документация CatLang

> Полная спецификация функционального языка программирования с кошачьим синтаксисом

---

## 1. Общие сведения

**CatLang** — интерпретируемый функциональный язык программирования, разработанный в рамках курсового проекта по функциональному программированию. Язык основан на лямбда-исчислении и реализован на **F#** с использованием библиотеки **FParsec** для парсинга и платформы **.NET 8.0**.

### 1.1. Философия языка

CatLang — эзотерический язык, в котором каждая синтаксическая конструкция стилизована под кошачьи звуки, повадки и эмоции.

**Основные принципы:**

1. **Код как мяуканье.** Программа выглядит так, будто один котик объясняет другому алгоритм. Ключевые слова — звуки и действия кошек: `meow` (let), `play_again!` (let rec), `UwU` (if), `happy:)` (then), `OwO` (else), `nya` (конец блока).

2. **Строгая математическая основа.** Несмотря на игровой синтаксис, под капотом — чистое лямбда-исчисление. Все функции каррированы, поддерживаются замыкания, рекурсия и pattern matching. Язык является Тьюринг-полным.

3. **Всё есть выражение.** В CatLang нет операторов-инструкций — всё возвращает значение. Даже условный блок `UwU...happy:)...OwO` возвращает результат вычисления одной из веток.

4. **Минимализм.** Нет точек с запятой, скобок для аргументов. Применение функции — `f please x` вместо `f(x)`, что делает код похожим на вежливую просьбу.

5. **Эмоциональная окраска.** Каждая операция несёт эмоциональный оттенок: `happy:)` — радость от истины, `OwO` — удивление от ложного условия, `hug()` — обнимашки (пустой список), `nya` — довольное мурчание в конце блока.

## 2. Грамматика языка (EBNF)

ebnf
program    = { definition | expression } ;

definition = ("meow" | "play_again!") identifier "0.0" lambda "nya" ;

lambda     = "cat_game" identifier "->" expression ;

expression = integer
           | "yesss;3"
           | "nooo:("
           | "hug()"
           | identifier
           | "UwU" expression "happy:)" expression "OwO" expression
           | "meow" identifier "0.0" expression "nya" expression
           | "play_again!" identifier "0.0" lambda "nya" expression
           | lambda
           | expression "please" expression
           | expression "::" expression
           | expression (":)" | ":(" | ":*" | "}:" ) expression
           | expression ("same_cats" | "not_same_cats" | "smaller_cat" | "bigger_cat" | "smol_or_equal_cat" | "big_or_equal_cat") expression
           | "say:3" expression
           | "listen:3"
           | "two_halves:3" expression "love>.<" { "|" pattern "->" expression } "nya"
           | "(" expression ")" ;

pattern    = "hug()"
           | identifier "::" identifier
           | identifier ;

integer    = digit { digit } ;
identifier = letter { letter | digit | "_" } ;

## 3. Семантика

### 3.1. Модель вычислений
CatLang использует энергичные вычисления (eager evaluation). Все аргументы функции вычисляются до подстановки в тело функции. Ленивые вычисления не поддерживаются.

### 3.2. Область видимости
Статическая (лексическая) область видимости — переменная видна в том блоке, где объявлена

Замыкания захватывают окружение в момент создания функции

meow x 0.0 значение nya — создаёт новую именованную привязку в текущей области

play_again! f 0.0 ... nya — создаёт рекурсивную привязку, функция видит сама себя

### 3.3. Каррирование
Все функции в CatLang каррированные. Функция от нескольких аргументов — это функция от одного аргумента, возвращающая функцию от остальных.

Пример:

meow add 0.0 cat_game x -> cat_game y -> x :) y nya
Применение: add please 2 please 3 эквивалентно ((add(2))(3)) и возвращает 5.

### 3.4. Алгоритм вычисления (eval)
Интерпретатор реализован как tree-walk interpreter. Функция eval принимает выражение и окружение, возвращает значение:

eval(env, expr):
  Int n              -> VInt n
  Bool b             -> VBool b
  Var x              -> env[x]              (поиск в окружении)
  Let(x, e1, e2)     -> v1 = eval(env, e1)
                        eval(env[x := v1], e2)
  LetRec(f, lam, e2) -> env' = env[f := VRecClosure(f, lam, env')]
                        eval(env', e2)
  Lambda(p, body)    -> VClosure(p, body, env)
  App(func, arg)     -> fVal = eval(env, func)
                        argVal = eval(env, arg)
                        если fVal = VClosure(p, body, clEnv):
                          eval(clEnv[p := argVal], body)
  If(cond, t, e)     -> если eval(env, cond) = VBool true
                        то eval(env, t)
                        иначе eval(env, e)
  Bin(op, a, b)      -> va = eval(env, a); vb = eval(env, b)
                        выполнить операцию
  Cons(h, t)         -> VList(eval(env, h) :: evalList(env, t))
  Match(e, cases)    -> v = eval(env, e)
                        проверить образцы по порядку
                        выполнить первое совпадение

## 4. Система типов
CatLang использует динамическую типизацию. Типы значений проверяются во время выполнения. При несовпадении типов в операциях возникает ошибка времени выполнения.

### 4.1. Типы значений
Тип	Пример значения	Описание
Int	42, -7, 0	32-битное целое число
Bool	yesss;3, nooo:(	Булево значение
Unit	(неявно)	Единичный тип, возвращается из say:3
List	1 :: 2 :: hug()	Связный список на cons-ячейках
Closure	cat_game x -> x :) 1	Замыкание (функция + окружение)
RecClosure	создаётся play_again!	Рекурсивное замыкание

### 4.2. Приведение типов
Автоматического приведения типов нет. Все операции требуют операнды одного типа.

## 5. Списки
### 5.1. Структура
Списки — односвязные, построены на cons-ячейках (::). Пустой список — hug().

### 5.2. Создание списка
meow numbers 0.0 (1 :: 2 :: 3 :: 4 :: hug()) nya

### 5.3. Операции над списками
Операция	Синтаксис	Сложность	Пример
Пустой список	hug()	O(1)	meow x 0.0 hug() nya
Добавить в голову	x :: xs	O(1)	0 :: numbers
Взять голову	first_cat please xs	O(1)	first_cat please numbers
Взять последний элемент	last_cat please xs	O(n)	last_cat please numbers

### 5.4. Пример работы со списками
meow mylist 0.0 (10 :: 20 :: 30 :: 40 :: hug()) nya

say:3 (first_cat please mylist)    | выводит: 10
say:3 (last_cat please mylist)     | выводит: 40

## 6. Pattern Matching
### 6.1. Синтаксис

two_halves:3 выражение love>.<
    | образец1 -> результат1
    | образец2 -> результат2
    ...
nya

### 6.2. Допустимые образцы

Образец	Когда совпадает	Пример
hug()	Выражение — пустой список	| hug() -> ...
h :: t	Выражение — непустой список	| h :: t -> ...
x	Любое значение (захват)	| x -> ...

### 6.3. Семантика
Образцы проверяются последовательно сверху вниз. Выполняется выражение справа от первого совпавшего образца. Если ни один образец не совпал — ошибка выполнения.

### 6.4. Пример

meow lst 0.0 (1 :: 2 :: 3 :: hug()) nya

two_halves:3 lst love>.<
    | hug() -> say:3 "Empty list"
    | h :: t -> 
        say:3 "Head:"
        say:3 h
        say:3 "Tail:"
        say:3 t
nya
Результат:

Head:
1
Tail:
(2 :: 3 :: hug())

## 7. Встроенные операторы и функции

### 7.1. Арифметические операторы
Все операторы требуют операнды типа Int. При несовпадении — ошибка выполнения.

Оператор	Сигнатура	Описание	Пример	Результат
:)	Int -> Int -> Int	Сложение	2 :) 3	5
:(	Int -> Int -> Int	Вычитание	10 :( 4	6
:*	Int -> Int -> Int	Умножение	6 :* 7	42
}:(	Int -> Int -> Int	Деление	8 }:( 2	4

### 7.2. Операторы сравнения
Возвращают Bool (yesss;3 или nooo:().

Оператор	Сигнатура	Описание
same_cats	Int -> Int -> Bool	Равенство
not_same_cats	Int -> Int -> Bool	Неравенство
smaller_cat	Int -> Int -> Bool	Меньше
bigger_cat	Int -> Int -> Bool	Больше
smol_or_equal_cat	Int -> Int -> Bool	Меньше или равно
big_or_equal_cat	Int -> Int -> Bool	Больше или равно

### 7.3. Ввод-вывод
Функция	Сигнатура	Описание	Пример
say:3	Any -> Unit	Выводит значение на экран	say:3 42
listen:3	Unit -> Int	Читает целое число с клавиатуры	meow x 0.0 listen:3 nya

## 8. Ограничения текущей реализации
Нет ленивых вычислений — все аргументы вычисляются энергично до подстановки

Нет оптимизации хвостовой рекурсии — глубокая рекурсия может привести к переполнению стека

Нет модульной системы — весь код должен находиться в одном файле, нет импортов

Нет строкового типа — строки поддерживаются только как литералы в say:3

Динамическая типизация — ошибки несоответствия типов обнаруживаются только во время выполнения

Нет алгебраических типов данных — нельзя определить пользовательский тип

Нет стандартной библиотеки — доступны только встроенные операторы

## 9. Сравнение с другими языками

| Конструкция | CatLang | F# | Haskell |
|-------------|---------|----|---------|
| Определение функции | `meow f 0.0 cat_game x -> b nya` | `let f x = b` | `f x = b` |
| Рекурсивная функция | `play_again! f 0.0 cat_game x -> b nya` | `let rec f x = b` | `f x = b` |
| Условие | `UwU c happy:) t OwO e` | `if c then t else e` | `if c then t else e` |
| Применение | `f please x` | `f x` | `f x` |
| Лямбда | `cat_game x -> x :) 1` | `fun x -> x + 1` | `\x -> x + 1` |
| Список | `1 :: 2 :: hug()` | `[1; 2]` | `[1, 2]` |
| Pattern matching | `two_halves:3 ... love>.<` | `match ... with` | `case ... of` |
| Вывод | `say:3 x` | `printfn "%A" x` | `print x` |

## 10. Архитектура интерпретатора
Интерпретатор реализован как tree-walk interpreter — обходит AST и вычисляет значения напрямую.

### 10.1. Структура проекта

```
cutelang/
├── src/
│   ├── Ast.fs              # AST (Expr, Pattern, BinOp)
│   ├── Value.fs            # Типы значений (VClosure, VList)
│   ├── Parser.fs           # Парсер на FParsec
│   ├── Interpreter.fs      # eval с окружением
│   └── Program.fs          # Точка входа
├── examples/
│   ├── fact.cat            # Факториал
│   ├── fib.cat             # Числа Фибоначчи
│   ├── map.cat             # Map
│   ├── lists.cat           # Списки
│   ├── match.cat           # Pattern matching
│   └── simple_math.cat     # Арифметика
├── CatLang.fsproj          # Проект F# (.NET 8.0)
├── .gitignore
└── README.md
```

### 10.2. Модули
Модуль	Файл	Назначение
AST	Ast.fs	Определения типов: Expr (выражения), Pattern (образцы), BinOp (бинарные операторы)
Значения	Value.fs	Типы значений: VInt, VBool, VUnit, VClosure, VRecClosure, VList, Env
Парсер	Parser.fs	Комбинаторный парсер на FParsec, преобразует исходный код в Expr
Интерпретатор	Interpreter.fs	Рекурсивная функция eval, вычисляет значение выражения в заданном окружении
Программа	Program.fs	Читает файл .cat, вызывает парсер, затем eval, выводит результат

### 10.3. Процесс выполнения
Чтение файла — Program.fs читает исходный код из .cat файла

Парсинг — Parser.fs преобразует текст в AST (тип Expr)

Вычисление — Interpreter.fs рекурсивно обходит AST и вычисляет значение

Вывод — результат последнего выражения выводится на экран
