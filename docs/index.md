# 🐱 Документация CatLang

Полная спецификация функционального языка с кошачьим синтаксисом.

---

## 1. Общие сведения

**CatLang** — интерпретируемый функциональный язык с кошачьим синтаксисом. Основан на лямбда-исчислении, поддерживает рекурсию, замыкания, каррирование и pattern matching. Реализован на F# с FParsec.

### 1.1. Философия языка

Каждая конструкция CatLang стилизована под кошачьи звуки. Код выглядит как диалог котиков, но семантически эквивалентен строгому функциональному языку.

---

## 2. Семантика

### 2.1. Модель вычислений

CatLang использует энергичные вычисления. Аргументы вычисляются до подстановки в тело.

### 2.2. Область видимости

- Статическая (лексическая) область видимости
- Замыкания захватывают окружение в момент создания
- `meow` — именованная привязка в текущей области
- `play_again!` — рекурсивная привязка

### 2.3. Каррирование

Все функции каррированные. `cat_game x -> cat_game y -> x :) y` — функция от двух аргументов.
Применение `f please a please b` эквивалентно `(f(a))(b)`.

---

## 3. Система типов

Динамическая типизация. Типы проверяются во время выполнения.

| Тип | Пример | Описание |
|-----|--------|----------|
| Int | `42` | 32-битное целое |
| Bool | `yesss;3`, `nooo:(` | Булево |
| List | `1 :: 2 :: hug()` | Связный список |
| Closure | `cat_game x -> x :) 1` | Замыкание |
| RecClosure | создается `play_again!` | Рекурсивное замыкание |

---

## 4. Списки

Списки — связные, на cons-ячейках. Пустой список: `hug()`.

| Операция | Синтаксис | Сложность |
|----------|-----------|-----------|
| Пустой список | `hug()` | O(1) |
| Добавить в голову | `x :: xs` | O(1) |
| Взять голову | `first_cat please xs` | O(1) |
| Взять хвост | `last_cat please xs` | O(n) |

---

## 5. Pattern Matching

```
two_halves:3 выражение love>.<
    | образец1 -> результат1
    | образец2 -> результат2
nya
```

| Образец | Описание |
|---------|----------|
| `hug()` | Пустой список |
| `h :: t` | Голова и хвост |
| `x` | Любое значение |

Образцы проверяются по порядку. Если ни один не совпал — ошибка выполнения.

## 6. Встроенные операторы

### Арифметика

| Оператор | Описание |
|----------|----------|
| `:)` | Сложение |
| `:(` | Вычитание |
| `:*` | Умножение |
| `}:(` | Деление |

### Сравнения

| Оператор | Описание |
|----------|----------|
| `same_cats` | Равенство |
| `not_same_cats` | Неравенство |
| `smaller_cat` | Меньше |
| `bigger_cat` | Больше |
| `smol_or_equal_cat` | Меньше или равно |
| `big_or_equal_cat` | Больше или равно |

### Ввод-вывод

| Функция | Описание |
|---------|----------|
| `say:3` | Вывод на экран |
| `listen:3` | Ввод числа |

---

## 7. Ограничения

- Нет ленивых вычислений — все аргументы вычисляются энергично
- Нет оптимизации хвостовой рекурсии — возможен stack overflow
- Нет модульной системы — весь код в одном файле
- Нет строкового типа — строки только в `say:3` как литералы
- Динамическая типизация — ошибки типов только во время выполнения

## 8. Сравнение с другими языками

| Конструкция | CatLang | F# | Haskell |
|-------------|---------|----|---------|
| Функция | `meow f 0.0 cat_game x -> ... nya` | `let f x = ...` | `f x = ...` |
| Рекурсия | `play_again! f 0.0 ...` | `let rec f x = ...` | `f x = ...` |
| Условие | `UwU ... happy:) ... OwO ...` | `if ... then ... else ...` | `if ... then ... else ...` |
| Применение | `f please x` | `f x` | `f x` |
| Лямбда | `cat_game x -> x :) 1` | `fun x -> x + 1` | `\x -> x + 1` |
| Список | `1 :: 2 :: hug()` | `[1; 2]` | `[1, 2]` |

## 9. Архитектура интерпретатора

| Модуль | Файл | Описание |
|--------|------|----------|
| AST | `Ast.fs` | Узлы дерева (Expr, Pattern, BinOp) |
| Значения | `Value.fs` | Типы времени выполнения (VClosure, VList) |
| Парсер | `Parser.fs` | FParsec, исходный код -> AST |
| Интерпретатор | `Interpreter.fs` | eval с окружением |
| Точка входа | `Program.fs` | Чтение файла, запуск |
